# resumo-do-lab-dio-rob
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO


No laboratório foi apresentada o painel do Azure, onde ficam todas as categorias e serviços organizados em nuvem;
Os portais são iguais para todos os públicos seja empresa grande ou pessoa física;
Podemos trocar o idioma do painel e a região, podemos também fazer personalização trocando disposições de tema e as cores;
Na guia “Todos os Serviços” são exibidas todas as categorias que vão desde ‘IA + Machine Learning, DevOps, Bancos de dados, Hibrido +multinuvem;
Na categoria “Computação” vimos Infraestrutura como Serviço (IaaS), que é um Danta center virtualizado que vai desde a virtualização de maquinas, chaves ssh, área de trabalho remota; já em Plataforma como Serviço (PaaS), tem aplicativos azure spring, Serviços de Aplicativos. Tem Nuvem Híbrida.
Na Categoria de Rede tem os Bastions que são tipo jump servers, para fazer uma rede segura de acesso as máquinas, tem subcategorias como endereços IP, Link, Firewall na Nuvem, emparelhamento de rede
Na Categoria Armazenamento, tem subcategoria de migração para nuvem, transferência de dados.
Também foi falado da versão previa que são serviços que não possuem uma “garantia” pois eles podem ou não serem implementados de forma definitiva, ou eles podem serem descontinuados (período de testes).
